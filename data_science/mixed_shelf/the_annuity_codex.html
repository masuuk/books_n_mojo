Chapter I

Time, Money, and the Seed

A dollar today is not a dollar tomorrow. This is the first and last law of finance.

If you plant a seed today, it will not remain a seed forever. Given soil, water, and time, it grows. Money behaves the same way: given an interest rate and time, it grows into something larger than itself.

The Future Value of a Single Sum

The future value (FV) of a present amount (PV) invested at an interest rate r per period for n periods is:

Formula 1.1 — Future Value FV = PV · (1 + r)n

The term (1 + r)n is called the Future Value Interest Factor (FVIF). It is the multiplier by which a single sum grows over time.

Formula 1.1 — in code

from std.math import pow

def fv_single(pv: Float64, r: Float64, n: Int) -> Float64:
    """FV = PV · (1 + r)^n"""
    return pv * pow(1.0 + r, Float64(n))

def main():
    # $1,000 at 6% for 10 years
    print("FV = $", fv_single(1000.0, 0.06, 10))  # 1790.847...

A small example

Invest $1,000 at 6% per year for 10 years. The FVIF is (1.06)10 ≈ 1.7908. Your $1,000 becomes $1,790.85. The extra $790.85 is the gift of time.

"Compound interest is the eighth wonder of the world. He who understands it, earns it; he who doesn't, pays it." — often attributed to A. Einstein

Chapter II

The Anatomy of an Annuity

A stream of equal payments, spaced evenly across time — the humble annuity.

Most financial decisions are not one-off. We save monthly, pay rent each month, receive dividends quarterly. An annuity is the mathematical name for such a stream.

Two Kinds of Annuity

Ordinary Annuity

Payments occur at the end of each period. Rent, mortgage payments, and most bond coupons are ordinary annuities.

Annuity Due

Payments occur at the beginning of each period. Lease payments and insurance premiums are often annuities due.

Because each payment in an annuity due earns interest for one extra period, its value is simply the ordinary-annuity value multiplied by (1 + r).

Why We Need New Formulas

Summing the future value of each individual payment one by one would be tedious. Fortunately, the payments form a geometric series, and the sum collapses into a single, elegant expression.

Chapter III

Future Value Interest Factor of Annuity

FVIFA — the multiplier that turns a stream of payments into a single future sum.

If you deposit PMT at the end of every period for n periods at rate r, the future value is:

Formula 3.1 — FV of an Ordinary Annuity FV = PMT · [ (1 + r)n − 1 ] / r

The bracketed term is the Future Value Interest Factor of Annuity, or FVIFA(r, n):

Formula 3.2 — FVIFA FVIFA(r, n) = [ (1 + r)n − 1 ] / r

So: FV = PMT × FVIFA(r, n).

Formulas 3.1 & 3.2 — in code

from std.math import pow

def fvifa(r: Float64, n: Int) -> Float64:
    """[ (1 + r)^n - 1 ] / r"""
    if r == 0.0:
        return Float64(n)
    return (pow(1.0 + r, Float64(n)) - 1.0) / r

def fv_annuity(pmt: Float64, r: Float64, n: Int, due: Bool = False) -> Float64:
    """FV = PMT × FVIFA(r, n), × (1 + r) if due"""
    var factor = fvifa(r, n)
    if due:
        factor *= (1.0 + r)
    return pmt * factor

def main():
    # $200 / month, 20 years, 7% compounded monthly
    var r = 0.07 / 12.0
    var n = 240
    print("FVIFA = ", fvifa(r, n))              # 520.9267...
    print("FV    = $", fv_annuity(200.0, r, n))  # 104185.34...

For an Annuity Due

Formula 3.3 — FV of Annuity Due FVdue = PMT · FVIFA(r, n) · (1 + r)

Formula 3.3 — one extra term

# Same stream, paid at the start of each period instead
var fv_due = fv_annuity(200.0, r, n, due=True)
print("FV due = $", fv_due)   # 104793.09...

A Numerical Example

Save $200 per month for 20 years at 7% annual interest, compounded monthly.

  • r = 0.07 / 12 = 0.005833…
  • n = 20 × 12 = 240
  • FVIFA ≈ 520.93
  • FV = 200 × 520.93 ≈ $104,186

Of that, only $48,000 was your own money. The rest — $56,186 — is the quiet labor of compounding.

Chapter IV

Present Value Interest Factor of Annuity

PVIFA — the mirror of FVIFA. How much is a stream of future payments worth today?

If someone promises to pay you PMT at the end of each period for n periods, what is that promise worth now?

Formula 4.1 — PV of an Ordinary Annuity PV = PMT · [ 1 − (1 + r)−n ] / r

The bracketed term is the Present Value Interest Factor of Annuity:

Formula 4.2 — PVIFA PVIFA(r, n) = [ 1 − (1 + r)−n ] / r

Formulas 4.1 & 4.2 — in code

from std.math import pow

def pvifa(r: Float64, n: Int) -> Float64:
    """[ 1 - (1 + r)^-n ] / r"""
    if r == 0.0:
        return Float64(n)
    return (1.0 - pow(1.0 + r, -Float64(n))) / r

def pv_annuity(pmt: Float64, r: Float64, n: Int, due: Bool = False) -> Float64:
    """PV = PMT × PVIFA(r, n), × (1 + r) if due"""
    var factor = pvifa(r, n)
    if due:
        factor *= (1.0 + r)
    return pmt * factor

def main():
    # $50,000 a year for 20 years, discounted at 5%
    print("PVIFA = ", pvifa(0.05, 20))              # 12.4622...
    print("PV    = $", pv_annuity(50000.0, 0.05, 20))  # 623110.50...

For an Annuity Due

Formula 4.3 — PV of Annuity Due PVdue = PMT · PVIFA(r, n) · (1 + r)

Formula 4.3 — one extra term

# The same lottery, paid at the start of each year
var pv_due = pv_annuity(50000.0, 0.05, 20, due=True)
print("PV due = $", pv_due)   # 654266.02...

The Relationship

Notice the elegant symmetry:

  • FVIFA grows with n — more time, more accumulation.
  • PVIFA shrinks with n — a payment far in the future is worth less today.
  • FV = PV × (1 + r)n, just as for single sums.

Example

A lottery offers $50,000 per year for 20 years. At a discount rate of 5%, PVIFA(5%, 20) ≈ 12.4622. The prize is worth $623,110 today — not the $1,000,000 headline.

Chapter V

Mojo 1.x, the Scribes

The formulas as code, function for function. Clean, readable, and yours to take.

Below is the full module behind the formulas in this book, written in Mojo 1.x. Every rate and payment is a typed Float64, so a percentage handed in where a decimal belongs is a compile error, not a silent wrong answer — and the compiled version evaluates a whole portfolio of annuities in the time an interpreter spends importing.

Here it is, function for function. Everything that distinguishes this from a scripting-language version of the same arithmetic is a compile-time guarantee: typed arguments and returns, pow with an explicit exponent, and no boxing of numbers on the heap:

from std.math import pow

def fvifa(r: Float64, n: Int) -> Float64:
    """Future Value Interest Factor of Annuity."""
    if r == 0.0:
        return Float64(n)
    return (pow(1.0 + r, Float64(n)) - 1.0) / r

def pvifa(r: Float64, n: Int) -> Float64:
    """Present Value Interest Factor of Annuity."""
    if r == 0.0:
        return Float64(n)
    return (1.0 - pow(1.0 + r, -Float64(n))) / r

def fv_annuity(pmt: Float64, r: Float64, n: Int, due: Bool = False) -> Float64:
    """Future value of an annuity."""
    var factor = fvifa(r, n)
    if due:
        factor *= (1.0 + r)
    return pmt * factor

def pv_annuity(pmt: Float64, r: Float64, n: Int, due: Bool = False) -> Float64:
    """Present value of an annuity."""
    var factor = pvifa(r, n)
    if due:
        factor *= (1.0 + r)
    return pmt * factor

# ---- Example ----
def main():
    var pmt = 200.0
    var annual_rate = 0.07
    var years = 20
    var freq = 12

    var r = annual_rate / Float64(freq)
    var n = years * freq

    print("FVIFA  = ", fvifa(r, n))
    print("PVIFA  = ", pvifa(r, n))
    print("FV     = $", fv_annuity(pmt, r, n))
    print("PV     = $", pv_annuity(pmt, r, n))

Using the Standard Library

Mojo 1.x has no numpy-financial — and for these closed-form formulas it doesn't need one. The standard library is enough, and the two lines you'd spend installing the dependency become the whole program. If the rest of your stack lives in Python, the same calls also ride the interop bridge (Python.import_module("numpy_financial")) while Mojo keeps the loop around them:

# No dependency needed — the factors are two lines each (see above).
# mojoproject.toml has no [dependencies] section at all.

def main():
    var pmt = 200.0
    var r = 0.07 / 12.0
    var n = 240

    print("FV = $", fv_annuity(pmt, r, n))
    print("PV = $", pv_annuity(pmt, r, n))

Amortization Table

A common companion task: printing a period-by-period schedule.

The amortization loop is where Mojo 1.x earns its keep: 360 rows for one mortgage is trivial, but a bank running sensitivity sweeps — thousands of rate scenarios × millions of loans — turns this exact loop into the hot path. Ported, it compiles to straight-line Float64 arithmetic with no interpreter between the rows:

from std.math import pow

def amortization(pv: Float64, annual_rate: Float64, years: Int, freq: Int = 12):
    var r = annual_rate / Float64(freq)
    var n = years * freq
    var pmt = pv * r / (1.0 - pow(1.0 + r, -Float64(n)))
    var balance = pv
    for i in range(1, n + 1):
        var interest = balance * r
        var principal = pmt - interest
        balance -= principal
        print(i, pmt, interest, principal, balance)

def main():
    amortization(250000.0, 0.06, 30)

Want the schedule as data instead of print lines? Accumulate the four columns into a Tensor[DType.float64](n, 4) and return it — the whole 30-year table is one contiguous allocation, ready for the sensitivity sweep or a chart.
