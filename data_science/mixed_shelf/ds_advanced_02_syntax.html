📜 Mojo 1.x Syntax & Semantics

def — the one function keyword, structs, value types, variables, control flow, and functions — the building blocks of Mojo code.

def: One Keyword, Two Flavors of Strictness

Mojo 1.x defines all functions with a single keyword: def. An unannotated def behaves like a Python function — lenient, great for scripting. A fully annotated def gives you parameters with explicit types, enforced raise checking, and stronger compiler optimization.

Mojo
# unannotated def — lenient, Python-like
def greet(name):
    return "Hello, " + name

# annotated def — strict, compiled, optimized
def add(a: Int, b: Int) -> Int:
    return a + b

def divide(a: Float64, b: Float64) raises -> Float64:
    if b == 0:
        raise "Division by zero"
    return a / b
Python-style indentation, all the way down

Mojo uses Python-style indentation and colons instead of curly braces — the bodies of def, if, and for are scoped purely by indentation. This is a deliberate design choice that keeps Mojo approachable for the millions of Python developers.

Annotate or not?

Annotate a def for compile-time safety, explicit type contracts, and maximum performance; leave annotations off for quick prototyping. The two forms are the same keyword — the annotations, not the declaration, decide how much the compiler can check.

Structs: Mojo's Primary Data Type

Structs are Mojo's value types. Unlike Python classes, structs are stack-allocated (by default), statically typed, and support zero-cost abstractions. They are the backbone of high-performance Mojo code.

Mojo
struct Point:
    var x: Float64
    var y: Float64

    def __init__(out self, x: Float64, y: Float64):
        self.x = x
        self.y = y

    def magnitude(self) -> Float64:
        return (self.x ** 2 + self.y ** 2).sqrt()

    def __add__(self, other: Point) -> Point:
        return Point(self.x + other.x, self.y + other.y)

var p = Point(3.0, 4.0)
print(p.magnitude())  # 5.0

var: The One Binding Keyword

Mojo 1.x declares every local variable with var — and the keyword is mandatory: a first assignment without var is a deprecation error. A variable you never reassign is your immutable binding.

Mojo
# constant by convention — declared once, never reassigned
var name = "Mojo"

# var — mutable binding
var counter = 0
counter += 1  # OK

# mut — pass-by-reference with mutation
def increment(mut x: Int):
    x += 1

var val = 10
increment(val)
print(val)  # 11
💡 Tip:

Python makes everything mutable by default; Mojo requires the explicit var declaration so the compiler always knows when a name enters scope. For values that must not change, simply never reassign them — compile-time constants belong in comptime aliases.

Control Flow

Mojo's control flow looks familiar if you know Python, but with stricter semantics. if, for, while, and match (pattern matching) all work as expected, with the added benefit that the compiler can optimize branches at compile time.

Mojo
# Pattern matching with match
def classify(x: Int) -> String:
    match x:
        case 0:
            return "zero"
        case 1 | 2 | 3:
            return "small"
        case _ if x > 0:
            return "positive"
        case _:
            return "negative"

# for loop with range
for i in range(5):
    print(i)

# while loop
var n = 10
while n > 0:
    n -= 1
@fieldwise_init decorator

Mojo 1.x's @fieldwise_init decorator generates the one-argument-per-field constructor for a struct (the role the old pre-1.0 @value decorator played). Pair it with trait conformances — struct S(Copyable, Equatable) — to get synthesized copy constructors and equality; it's the equivalent of Python's @dataclass but for Mojo value types.

Advanced Function Features

Mojo functions support raising declarations, parameterized types (generics), and closures. These features let you write highly reusable, type-safe code without sacrificing ergonomics.

Mojo
# Raising functions
def parse_int(s: String) raises -> Int:
    return int(s)

# Generic / parameterized functions
def max_of[T: Comparable](a: T, b: T) -> T:
    if a > b:
        return a
    return b

# Closures as first-class values
def apply[T: AnyType, U: AnyType](f: T -> U, x: T) -> U:
    return f(x)

var double = lambda x: x * 2
print(apply(double, 21))  # 42

Mojo's parameterized types use square-bracket syntax — [T: Constraint] — instead of angle brackets, so generic declarations read more like Python while still giving the compiler full type information.
