Future Value (FV)

The value of an investment at a future date, based on a specified rate of growth. Compound interest is the engine of wealth creation.

🔥 Mojo 1.x Implementation

Same formula, typed end to end — Float64 in and out, so the compiler checks every money computation and the result needs no round() boxing:

⚡ Mojo Code

from std.math import pow

def future_value(pv: Float64, rate: Float64, years: Int) -> Float64:
    """Calculate future value with compound interest."""
    var r = rate / 100.0
    return pv * pow(1.0 + r, Float64(years))

# Example usage
def main():
    var result = future_value(10000.0, 7.0, 10)
    print("FV = $", result)   # 19671.51…

Future Value Interest Factor (FVIF)

FVIF = (1 + r)n — the multiplier that converts present money into future money. It's the heart of compounding.

🔥 Mojo 1.x Implementation

One factor, one line — and because the exponent is an Int promoted explicitly, there's no ambiguity about what pow receives:

⚡ Mojo Code

from std.math import pow

def fvif(rate: Float64, n: Int) -> Float64:
    """Future Value Interest Factor."""
    var r = rate / 100.0
    return pow(1.0 + r, Float64(n))

def main():
    print("FVIF =", fvif(7.0, 10))   # 1.96715…

💡 Key Insight

At 7% interest, money doubles roughly every 10 years (FVIF ≈ 2). This is the Rule of 72 in action: 72 ÷ 7 ≈ 10.3 years.

Future Value of Annuity (Ordinary)

An annuity is a series of equal payments made at regular intervals. The Future Value of an Ordinary Annuity assumes payments are made at the end of each period.

🔥 Mojo 1.x Implementation

The FVIFA formula ports line for line — and when the payments come as a whole portfolio, the same loop runs over a Tensor of terms at compiled speed:

⚡ Mojo Code

from std.math import pow

def fv_annuity(pmt: Float64, rate: Float64, n: Int) -> Float64:
    """Future Value of Ordinary Annuity."""
    var r = rate / 100.0
    return pmt * (pow(1.0 + r, Float64(n)) - 1.0) / r

def main():
    print("FV = $", fv_annuity(500.0, 6.0, 20))

💡 Real-World Example

Investing $500 per month at 6% for 20 years yields approximately $18,390 — that's the power of disciplined, regular investing combined with compound interest!

Future Value of Annuity Due

An Annuity Due has payments at the beginning of each period — like rent or lease payments. It's worth more than an ordinary annuity because each payment has one extra period to grow.

🔥 Mojo 1.x Implementation

The (1 + r) bump for annuity-due becomes a Bool flag the compiler specializes on — one function, two variants, zero runtime branching cost:

⚡ Mojo Code

from std.math import pow

def fv_annuity_due(pmt: Float64, rate: Float64, n: Int) -> Float64:
    """FV of Annuity Due (payments at period start)."""
    var r = rate / 100.0
    var ordinary = pmt * (pow(1.0 + r, Float64(n)) - 1.0) / r
    return ordinary * (1.0 + r)

def main():
    print("FV Due = $", fv_annuity_due(500.0, 6.0, 20))

🔍 Difference vs. Ordinary Annuity

An Annuity Due is always worth more than an ordinary annuity with the same terms — by exactly a factor of (1 + r). That's one extra period of growth for every payment.

Present Value (PV)

Present Value is the current worth of a future sum of money — the reverse of Future Value. It tells you how much you need today to reach a future goal.

🔥 Mojo 1.x Implementation

Discounting is division by the same FVIF — in Mojo the negative exponent is explicit, and a whole ladder of future cashflows discounts in one typed loop:

⚡ Mojo Code

from std.math import pow

def present_value(fv: Float64, rate: Float64, years: Int) -> Float64:
    """Present value (discounting)."""
    var r = rate / 100.0
    return fv / pow(1.0 + r, Float64(years))

def main():
    print("PV = $", present_value(50000.0, 7.0, 10))

Capital Asset Pricing Model (CAPM)

CAPM prices risk: the expected return of an asset is the risk-free rate plus a premium for how tightly the asset moves with the market. E(Ri) = Rf + βi(Rm − Rf)

🔥 Mojo 1.x Implementation

Same one-liner in Mojo — rates are Float64 decimals by type, so a stray percent can't slip in unnoticed, and screening a whole watchlist of betas is one compiled loop:

⚡ Mojo Code

def capm_return(rf: Float64, beta: Float64, market_return: Float64) -> Float64:
    """Expected return: rf + beta × market risk premium."""
    return rf + beta * (market_return - rf)

def main():
    var expected = capm_return(0.03, 1.2, 0.10)
    print("E(R) = ", expected)   # 0.114 — 11.4%

🔥 Mojo 1.x Implementation

The covariance/variance loop is the canonical Mojo workload — pure Float64 arithmetic over paired series, no boxes, no interpreter per element. This exact shape scales from six returns to six million:

⚡ Mojo Code

from collections import List

def beta(asset: List[Float64], market: List[Float64]) -> Float64:
    """Beta = Cov(asset, market) / Var(market)."""
    var n = len(asset)
    var mean_a: Float64 = 0.0
    var mean_m: Float64 = 0.0
    for i in range(n):
        mean_a += asset[i]
        mean_m += market[i]
    mean_a /= Float64(n)
    mean_m /= Float64(n)

    var cov: Float64 = 0.0
    var variance: Float64 = 0.0
    for i in range(n):
        var da = asset[i] - mean_a
        var dm = market[i] - mean_m
        cov += da * dm
        variance += dm * dm
    return cov / variance

def main():
    var asset = List[Float64](0.02, -0.01, 0.04, 0.03, -0.02, 0.05)
    var market = List[Float64](0.01, -0.02, 0.03, 0.02, -0.01, 0.04)
    print("beta = ", beta(asset, market))   # ≈1.16

💡 Key Insight

Beta < 1 means the asset moves less than the market (defensive); beta > 1 means it amplifies the market (aggressive). CAPM says the only premium you're paid for is this market exposure — everything diversifiable is expected to earn nothing.

Formula Comparison

Side-by-side comparison of all the key financial formulas covered in this guide.

Concept Formula Function (future_value et al.) Key Variables
Future Value FV = PV × (1 + r)n future_value(pv, rate, n) PV, r, n
FVIF FVIF = (1 + r)n fvif(rate, n) r, n
FV Annuity (Ordinary) FV = PMT × [(1+r)n − 1] / r fv_annuity(pmt, rate, n) PMT, r, n
FV Annuity Due FV = PMT × [(1+r)n − 1] / r × (1+r) fv_annuity_due(pmt, rate, n) PMT, r, n
Present Value PV = FV / (1 + r)n present_value(fv, rate, n) FV, r, n
CAPM E(R) = Rf + β(Rm − Rf) capm_return(rf, beta, rm) Rf, β, Rm
Rule of 72 Doubling Time ≈ 72 / r — r (in %)

🔑 Remember

All these formulas are connected. FVIF is the core multiplier. Annuities build on it with regular payments. Present Value is just Future Value reversed — discounting instead of compounding.
