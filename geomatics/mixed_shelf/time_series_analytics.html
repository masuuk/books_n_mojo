Chapter 1

1. Introduction to Time Series Analysis

A forecast is only as good as the series it stands on — and one series, followed honestly through the whole book, lets every method be compared without excuses.

A time series is a sequence of data points indexed in chronological order. Unlike cross-sectional data, time series observations are dependent on their temporal ordering — the value at time t is often correlated with values at t−1, t−2, and so on. This autocorrelation is what makes time series analysis both challenging and powerful.

1.1 Components of a Time Series

Classical decomposition breaks a time series into four additive or multiplicative components:

ComponentDescriptionExample in our data
Trend (T)Long-term directionSteady increase from ~120 to ~280
Seasonality (S)Regular, fixed-period cyclesYearly dips at months 8 and 16
Cyclical (C)Irregular, longer-term cyclesBusiness cycle effects
Noise (ε)Random, unpredictable variationScatter around the trend line

1.2 Why Time Series for ML?

Machine learning models can capture complex non-linear patterns that classical statistical models miss. However, they require careful feature engineering (lag variables, rolling statistics, etc.) to respect temporal structure. Understanding classical methods provides the foundation for designing effective ML features.

1.3 Additive vs. Multiplicative Decomposition

📐 Decomposition Models

Additive:  Y(t) = T(t) + S(t) + C(t) + ε(t)   (constant amplitude seasonality)
Multiplicative:  Y(t) = T(t) × S(t) × C(t) × ε(t)   (seasonal amplitude grows with trend)

For our sales data, the seasonal dips appear roughly constant in magnitude (≈15-20 units below trend), suggesting an additive model is appropriate.

2.3 Resampling and Aggregation

Mojo 1.x
# Resampling is just "average each fixed-size bucket of the series".
# 24 monthly observations -> 8 quarters -> 2 years, no index required.
def resample_mean(data: List[Float64], bucket: Int) -> List[Float64]:
    var n = len(data)
    var out = List[Float64]()
    var i = 0
    while i < n:
        var stop = i + bucket
        if stop > n:
            stop = n                     # a short final bucket is fine
        var total: Float64 = 0.0
        for j in range(i, stop):
            total += data[j]
        out.append(total / Float64(stop - i))
        i = stop
    return out

def resample_sum(data: List[Float64], bucket: Int) -> List[Float64]:
    var n = len(data)
    var out = List[Float64]()
    var i = 0
    while i < n:
        var stop = i + bucket
        if stop > n:
            stop = n
        var total: Float64 = 0.0
        for j in range(i, stop):
            total += data[j]
        out.append(total)
        i = stop
    return out

def main():
    var sales = load_sales_data()
    var quarterly = resample_mean(sales, 3)     # 24 months -> 8 quarters
    var yearly = resample_sum(sales, 12)        # 24 months -> 2 years
    print("Quarterly means:", quarterly)
    print("Yearly totals:", yearly)

3. Moving Averages & Smoothing

A smooth line reveals the trend hiding under noise.

Moving averages are the simplest and most widely used smoothing technique. They reduce noise and reveal underlying trend by averaging over a sliding window.

3.1 Simple Moving Average (SMA)

The SMA of window size k at time t is: SMA(t) = (Y(t-k+1) + ... + Y(t)) / k

Mojo 1.x
# Simple moving average implemented over List[Float64]
def sma(data: List[Float64], window: Int) -> List[Float64]:
    var n = len(data)
    var result = List[Float64]()              # will hold n - window + 1 values
    for i in range(window, n + 1):
        var sum: Float64 = 0.0
        for j in range(i - window, i):        # window ending at index i
            sum += data[j]
        result.append(sum / Float64(window))
    return result

def main():
    var sales = load_sales_data()
    var sma3 = sma(sales, 3)     # 22 values
    var sma6 = sma(sales, 6)     # 19 values
    var sma12 = sma(sales, 12)   # 13 values
    print("SMA(3) first:", sma3[0], sma3[1], sma3[2])
    print("SMA(6) first:", sma6[0])
    print("SMA(12) first:", sma12[0], sma12[1])

3.3 Exponential Smoothing

Exponential smoothing applies geometrically decreasing weights to past observations. The smoothing factor α (0 < α < 1) controls the decay rate.

Formula: S(t) = α·Y(t) + (1−α)·S(t−1)

Mojo 1.x
# Simple exponential smoothing:
#   s[t] = alpha * x[t] + (1 - alpha) * s[t-1]
def exponential_smoothing(data: List[Float64], alpha: Float64) -> List[Float64]:
    var n = len(data)
    var result = List[Float64]()
    result.append(data[0])                    # seed with the first observation
    for i in range(1, n):
        result.append(alpha * data[i] + (1.0 - alpha) * result[i - 1])
    return result

def main():
    var sales = load_sales_data()
    var ses = exponential_smoothing(sales, 0.3)
    print("SES with alpha=0.3:", ses[0], ses[1], ses[2], ses[3], ses[4])

4. Time Series Decomposition

Yearly rhythms — holidays, climate, budget cycles — echo at lag 12, and decomposition splits the series so each rhythm can be studied alone.

Seasonality is the most dependable pattern in monthly data: a seasonal lag compares each month to the same month a year earlier, and a seasonal index averages each position in the year across all years. Decomposition splits the series into trend + seasonal + residual so each can be studied alone.

4.1 Mojo 1.x: Manual Decomposition via Moving Averages

Mojo 1.x
# Manual additive decomposition:
#   trend    = centered moving average (of length `period`)
#   seasonal = average detrended value for each position inside the period
#   residual = data - trend - seasonal
def decompose_trend_seasonal(data: List[Float64], period: Int) -> Tuple[
    List[Float64], List[Float64], List[Float64]]:
    var n = len(data)
    var half = period // 2
    # Step 1: trend via centered moving average
    var trend = List[Float64]()
    var detrended = List[Float64]()
    var seasonal = List[Float64]()
    var residual = List[Float64]()
    for i in range(n):                  # preallocate with zeros for later writes
        trend.append(0.0)
        detrended.append(0.0)
        seasonal.append(0.0)
        residual.append(0.0)
    for i in range(half, n - half):
        var sum: Float64 = 0.0
        for j in range(i - half, i + half + 1):
            sum += data[j]
        trend[i] = sum / Float64(2 * half + 1)
    # Step 2: detrended series = data - trend
    for i in range(n):
        detrended[i] = data[i] - trend[i]
    # Step 3: seasonal component = average detrended value per period position
    for p in range(period):
        var sum: Float64 = 0.0
        var count = 0
        var i = p
        while i < n:                    # step by `period` with a while loop
            if trend[i] != 0.0:
                sum += detrended[i]
                count += 1
            i += period
        var avg = 0.0
        if count > 0:                   # avoid division by zero
            avg = sum / Float64(count)
        var k = p
        while k < n:
            seasonal[k] = avg
            k += period
    # Step 4: residual = data - trend - seasonal
    for i in range(n):
        residual[i] = data[i] - trend[i] - seasonal[i]
    return (trend, seasonal, residual)

def main():
    var sales = load_sales_data()
    var trend, seasonal, resid = decompose_trend_seasonal(sales, 12)
    print("Trend M1-M6:", trend[0], trend[1], trend[2], trend[3], trend[4], trend[5])
    print("Seasonal M1-M4:", seasonal[0], seasonal[1], seasonal[2], seasonal[3])

5. Stationarity & Differencing

Most models presume a stable mean and variance; the data decide when they do not get one.

Many time series models (especially ARIMA) require the data to be stationary — constant mean, variance, and autocorrelation over time. Our sales data has a clear trend, so it is non-stationary.

5.1 Augmented Dickey-Fuller (ADF) Test

📐 Worked Example: ADF on Original Data

ADF Statistic ≈ +0.85 (positive — typical for trending series)
p-value ≈ 0.99 → Fail to reject H₀ → Non-stationary
H₀: unit root exists (non-stationary); H₁: stationary

📐 Worked Example: ADF on First Difference

ADF Statistic ≈ -4.32 → p-value ≈ 0.001 → Reject H₀ → Stationary

5.2 First-Order Differencing

Mojo 1.x
# Nth-order differencing: each pass replaces the series with its first difference
def difference(data: List[Float64], order: Int) -> List[Float64]:
    var result = data
    for d in range(order):
        var temp = List[Float64]()
        for i in range(1, len(result)):
            temp.append(result[i] - result[i - 1])
        result = temp                  # each pass drops one observation
    return result

def main():
    var sales = load_sales_data()
    var diff1 = difference(sales, 1)   # 23 values
    var diff2 = difference(sales, 2)   # 22 values
    print("First differences:", diff1[0], diff1[1], diff1[2], diff1[3], diff1[4])

6. ARIMA Models

Autoregression, differencing, and a moving average of past errors — together they describe a huge family of series.

ARIMA (AutoRegressive Integrated Moving Average) is the workhorse of classical time series forecasting. It combines three components: AR (regression on lagged values), I (differencing), and MA (regression on lagged forecast errors).

6.1 ARIMA(p, d, q) Notation

ParameterMeaningHow to Determine
pAR order (lag terms)PACF plot — significant lags
dDifferencing orderADF test — until stationary
qMA order (error terms)ACF plot — significant lags

6.2 Mojo 1.x: Manual AR(1) Implementation

Mojo 1.x
# AR(1) model: Y(t) = c + phi * Y(t-1) + eps(t), fitted by least squares
def fit_ar1(data: List[Float64]) -> Tuple[Float64, Float64]:
    var n = len(data)
    var sum_x: Float64 = 0.0
    var sum_y: Float64 = 0.0
    var sum_xy: Float64 = 0.0
    var sum_xx: Float64 = 0.0
    for i in range(1, n):
        var x = data[i - 1]           # lagged value
        var y = data[i]               # current value
        sum_x += x
        sum_y += y
        sum_xy += x * y
        sum_xx += x * x
    var count = Float64(n - 1)
    # slope (phi) and intercept (c) from the normal equations
    var phi = (count * sum_xy - sum_x * sum_y) / (count * sum_xx - sum_x * sum_x)
    var c = (sum_y - phi * sum_x) / count
    return (c, phi)

# Iterate the fitted recursion one step at a time into the future
def forecast_ar1(data: List[Float64], steps: Int) -> List[Float64]:
    var c, phi = fit_ar1(data)        # destructure the returned pair
    var last = data[len(data) - 1]
    var result = List[Float64]()
    var prev = last
    for i in range(steps):
        var next_val = c + phi * prev
        result.append(next_val)
        prev = next_val               # each step consumes the previous forecast
    return result

def main():
    var sales = load_sales_data()
    var c, phi = fit_ar1(sales)
    print("AR(1) model: c =", c, ", phi =", phi)
    var fc = forecast_ar1(sales, 6)
    print("6-step forecast:", fc[0], fc[1], fc[2], fc[3], fc[4], fc[5])

📐 Worked Example: AR(1) Coefficient Estimate

Using least squares on Y(t) = c + φ·Y(t-1):

n = 23 pairs (M2-M1, M3-M2, ..., M24-M23)
Σx = Σ(Y(t-1)) = 120 + 132 + ... + 270 = 4597
Σy = Σ(Y(t)) = 132 + 145 + ... + 280 = 4712
Σxy = 120×132 + 132×145 + ... + 270×280 ≈ 1,098,990
Σx² = 120² + 132² + ... + 270² ≈ 1,056,929
φ = (23×1,098,990 - 4597×4712) / (23×1,056,929 - 4597²)
φ = (25,276,770 - 21,663,064) / (24,309,367 - 21,132,409)
φ = 3,613,706 / 3,176,958 = 1.137
c = (4712 - 1.137×4597)/23 = (4712 - 5227.7)/23 = -22.42

Note: φ > 1 indicates a non-stationary process — expected for trending data. This confirms d=1 differencing is needed.

7. Exponential Smoothing (Holt-Winters)

Add a trend and a seasonal cycle, and single smoothing becomes the classic triple method — three ideas kept in flight at once.

Holt-Winters keeps three ideas in flight at once: a level, a trend, and a seasonal factor for each position in the year. Three recursions update them month by month, and the forecast simply adds them back together — the strongest classical tool in this book, and because statsmodels is reachable through interop, you can compare against it in two lines.

7.1 Triple Exponential Smoothing (Holt-Winters)

Parameters: α (level), β (trend), γ (seasonality), with seasonal period m.

Mojo 1.x
# Holt-Winters additive triple exponential smoothing, written from scratch
def holt_winters_additive(data: List[Float64], period: Int,
                          alpha: Float64, beta: Float64, gamma: Float64
                          ) -> List[Float64]:
    var n = len(data)
    var level = List[Float64]()
    var trend = List[Float64]()
    var seasonal = List[Float64]()
    var fitted = List[Float64]()
    for i in range(n):                 # preallocate for later indexed writes
        level.append(0.0)
        trend.append(0.0)
        seasonal.append(0.0)
        fitted.append(0.0)
    # initialize level and trend from the first two observations
    level[0] = data[0]
    trend[0] = data[1] - data[0]
    # initialize one seasonal index per position in the period
    for i in range(period):
        seasonal[i] = data[i] - level[0]
    for t in range(n):
        if t >= period:
            var prev_seasonal = seasonal[t - period]
            var prev_level = level[t - 1]
            var prev_trend = trend[t - 1]
            # the three smoothing equations: level, trend, seasonal
            level[t] = alpha * (data[t] - prev_seasonal) + (1.0 - alpha) * (prev_level + prev_trend)
            trend[t] = beta * (level[t] - prev_level) + (1.0 - beta) * prev_trend
            seasonal[t] = gamma * (data[t] - level[t]) + (1.0 - gamma) * prev_seasonal
            fitted[t] = level[t] + trend[t] + seasonal[t - period]
    return fitted

def main():
    var sales = load_sales_data()
    var fitted = holt_winters_additive(sales, 12, 0.3, 0.1, 0.1)
    print("Fitted values (M13-M18):", fitted[12], fitted[13], fitted[14],
          fitted[15], fitted[16], fitted[17])

📐 Worked Example: Holt-Winters Update (α=0.3, β=0.1, γ=0.1)

Initialization (first 12 months):

7.2 Holt's Linear Trend Method (Double Exponential Smoothing)

Use when there's trend but no seasonality. Our data has both, but for illustration:

Mojo 1.x
# Holt's linear trend: level + trend, no seasonality.
#   level[t] = alpha * y[t] + (1 - alpha) * (level[t-1] + trend[t-1])
#   trend[t] = beta  * (level[t] - level[t-1]) + (1 - beta) * trend[t-1]
#   forecast = level[n-1] + h * trend[n-1]        for h = 1 .. horizon
def holt_linear(
    data: List[Float64], alpha: Float64, beta: Float64, horizon: Int
) -> Tuple[List[Float64], List[Float64]]:
    var n = len(data)
    var fitted = List[Float64]()
    var level = data[0]
    var trend = data[1] - data[0]          # seed the trend from the first pair
    fitted.append(level)
    for i in range(1, n):
        var previous = level
        level = alpha * data[i] + (1.0 - alpha) * (level + trend)
        trend = beta * (level - previous) + (1.0 - beta) * trend
        fitted.append(level)
    var forecast = List[Float64]()
    for h in range(1, horizon + 1):
        forecast.append(level + Float64(h) * trend)
    return (fitted, forecast)

def main():
    var sales = load_sales_data()
    var result = holt_linear(sales, 0.5, 0.3, 3)
    var fitted = result[0]
    var forecast = result[1]
    print("Fitted level, last 4:", fitted[20], fitted[21], fitted[22], fitted[23])
    print("Holt's forecast:", forecast)
💡 Choosing α, β, γ Larger α responds faster to level changes; larger β tracks trend faster; larger γ adapts seasonality quicker. Use cross-validation or grid search to find optimal values.

8. Feature Engineering for ML

Machine learning models require tabular features. For time series, we create lag features, rolling statistics, and date-based features to capture temporal patterns.

8.1 Feature Engineering: Lags, Rolling Windows and Calendar Cycles

Mojo 1.x
# Feature engineering in pure Mojo.
# The lag matrix is stored flat (row-major): element [i, j] of the matrix
# lives at flat index i * max_lag + j.
from std.math import cos, sin, sqrt
def create_lag_features(data: List[Float64], max_lag: Int) -> List[Float64]:
    var n = len(data)
    var rows = n - max_lag
    var result = List[Float64]()
    for i in range(rows * max_lag):
        result.append(0.0)             # preallocate, then write below
    for i in range(max_lag, n):
        for lag in range(1, max_lag + 1):
            result[(i - max_lag) * max_lag + (lag - 1)] = data[i - lag]
    return result

# Rolling mean feature over a fixed window
def create_rolling_mean(data: List[Float64], window: Int) -> List[Float64]:
    var n = len(data)
    var result = List[Float64]()
    for i in range(window, n + 1):
        var sum: Float64 = 0.0
        for j in range(i - window, i):
            sum += data[j]
        result.append(sum / Float64(window))
    return result

# Rolling standard deviation over the same window (population sigma).
def create_rolling_std(data: List[Float64], window: Int) -> List[Float64]:
    var n = len(data)
    var result = List[Float64]()
    for i in range(window, n + 1):
        var sum: Float64 = 0.0
        for j in range(i - window, i):
            sum += data[j]
        var mean = sum / Float64(window)
        var variance: Float64 = 0.0
        for j in range(i - window, i):
            var d = data[j] - mean
            variance += d * d
        result.append(sqrt(variance / Float64(window)))
    return result

# Calendar features. Month is a cycle, not a number, so encode it as a
# point on the unit circle: M1 -> (sin 2*pi/12, cos 2*pi/12), and so on.
# That keeps December adjacent to January instead of 11 units away.
def create_month_cycle(months: List[Int]) -> Tuple[List[Float64], List[Float64]]:
    var sin_part = List[Float64]()
    var cos_part = List[Float64]()
    for m in months:
        var angle = 2.0 * 3.141592653589793 * Float64(m) / 12.0
        sin_part.append(sin(angle))
        cos_part.append(cos(angle))
    return (sin_part, cos_part)

def main():
    var sales = load_sales_data()
    var lags = create_lag_features(sales, 3)
    var roll_mean = create_rolling_mean(sales, 3)
    var roll_std = create_rolling_std(sales, 3)
    # M1..M24 as calendar month numbers (1 = January)
    var months = List[Int]()
    for i in range(len(sales)):
        months.append(i % 12 + 1)
    var cycle = create_month_cycle(months)
    print("Lag features length:", len(lags))
    # first flat row (indexes 0..2) = data[2], data[1], data[0] (the three
    # values that precede the first fully-populated row)
    print("First lag row (lags 1,2,3):", lags[0], lags[1], lags[2])
    print("Rolling mean, first 3:", roll_mean[0], roll_mean[1], roll_mean[2])
    print("Rolling std, first 3:", roll_std[0], roll_std[1], roll_std[2])
    print("Month 13 cycle (sin, cos):", cycle[0][12], cycle[1][12])

# Sequence preparation. An LSTM consumes fixed-length windows, not raw
# series, so slide a window of `window` past the data and pair each window
# with the single value that follows it. The result is flat and row-major:
# window [i, j] lives at i * window + j, which is exactly the layout

Never shuffle — time is the one order that must always stay intact — and read the error through three lenses, because MAE, RMSE and MAPE change the answer whenever misses are uneven.

Proper evaluation is critical. Time series require time-based cross-validation (never random shuffling) and appropriate error metrics.

Mojo 1.x
# Error metrics, computed natively - no metrics library required.
from std.math import abs, sqrt

def mae(actual: List[Float64], predicted: List[Float64]) -> Float64:
    var total: Float64 = 0.0
    for i in range(len(actual)):
        total += abs(actual[i] - predicted[i])
    return total / Float64(len(actual))

def rmse(actual: List[Float64], predicted: List[Float64]) -> Float64:
    var total: Float64 = 0.0
    for i in range(len(actual)):
        var d = actual[i] - predicted[i]
        total += d * d
    return sqrt(total / Float64(len(actual)))

def mape(actual: List[Float64], predicted: List[Float64]) -> Float64:
    var total: Float64 = 0.0
    for i in range(len(actual)):
        total += abs(actual[i] - predicted[i]) / actual[i]
    return 100.0 * total / Float64(len(actual))

# Score one model and print the three-metric row the tables in this
# chapter quote.
def evaluate(actual: List[Float64], predicted: List[Float64],
             model_name: String):
    var e_mae = mae(actual, predicted)
    var e_rmse = rmse(actual, predicted)
    var e_mape = mape(actual, predicted)
    print(model_name, "| MAE:", e_mae, "| RMSE:", e_rmse, "| MAPE:", e_mape, "%")
    return (e_mae, e_rmse, e_mape)

11.3 Time Series Cross-Validation (Walk-Forward)

Mojo 1.x
# Walk-forward splits: train on an expanding window, validate on the
# next `horizon` observations. Time order is never shuffled.
# Each element of the result is a (train_end, val_end) index pair.
def walk_forward_splits(n: Int, n_splits: Int, horizon: Int) -> List[Tuple[Int, Int]]:
    var out = List[Tuple[Int, Int]]()
    var first_train = n - horizon * n_splits
    for k in range(n_splits):
        var train_end = first_train + horizon * k
        out.append((train_end, train_end + horizon))
    return out

# The "model" here is deliberately trivial - the mean of the training
# window - so the split logic is what the example is actually showing.
def window_mean_forecast(data: List[Float64], train_end: Int,
                         horizon: Int) -> List[Float64]:
    var total: Float64 = 0.0
    for i in range(train_end):
        total += data[i]
    var level = total / Float64(train_end)
    var out = List[Float64]()
    for _ in range(horizon):
        out.append(level)            # flat forecast at the window mean
    return out

def main():
    var sales = load_sales_data()
    var splits = walk_forward_splits(len(sales), 5, 2)
    for k in range(len(splits)):
        var train_end = splits[k][0]
        var val_end = splits[k][1]
        print("Fold", k, ": Train=0..", train_end, ", Validation=", train_end, "..", val_end)
        var predicted = window_mean_forecast(sales, train_end, val_end - train_end)
        print("   predicted:", predicted)

11.4 Backtesting

Mojo 1.x
# Backtesting: roll the origin forward, refit on everything seen so far,
# and accumulate the error of every prediction the model would have made
# live. The mean of those errors is the honest generalisation estimate.
def backtest_mae(data: List[Float64], n_splits: Int, horizon: Int) -> Float64:
    var first_train = len(data) - horizon * n_splits
    var error_total: Float64 = 0.0
    var count: Int = 0
    for k in range(n_splits):
        var train_end = first_train + horizon * k
        # refit: the window mean is the model
        var level: Float64 = 0.0
        for i in range(train_end):
            level += data[i]
        level /= Float64(train_end)
        # score the next `horizon` steps from that level
        for h in range(horizon):
            var err = data[train_end + h] - level
            if err < 0.0:
                err = -err
            error_total += err
            count += 1
    return error_total / Float64(count)

def main():
    var sales = load_sales_data()
    var avg_error = backtest_mae(sales, 4, 3)
    print("Average walk-forward MAE:", avg_error)
⚠️ Common Pitfall Never use train_test_split with shuffle=True for time series. Random shuffling destroys temporal dependencies and leads to data leakage (future information leaks into training).

14. Autocorrelation

ACF measures how strongly each value remembers its past — it is the single most useful plot in time series.

Autocorrelation measures how strongly a series is related to its own previous values. It is the key diagnostic for choosing AR model orders (via the ACF/PACF plots) and for detecting seasonality.

📐 Autocorrelation Formula

ρk = Cov(Xt, Xt−k) / Var(X)
Mojo 1.x
# Population variance implemented directly
def variance(data: List[Float64]) -> Float64:
    var total = 0.0
    for x in data:
        total += x
    var mean = total / Float64(len(data))
    var ss = 0.0
    for x in data:
        ss += (x - mean) * (x - mean)
    return ss / Float64(len(data))

After first differencing (Chapter 5), autocorrelation drops sharply — a sign the differenced series is closer to stationary. # Multivariate features: one row per time step, one column per variable,
# stored flat and row-major - element [i, j] lives at i * n_cols + j, the
# same layout the lag matrix uses earlier in this chapter.
def build_design_matrix(
    sales: List[Float64], price: List[Float64], rainfall: List[Float64]
) -> List[Float64]:
    var n = len(sales)
    var out = List[Float64]()
    for i in range(n):
        out.append(sales[i])        # column 0: the lagged target
        out.append(price[i])        # column 1: exogenous
        out.append(rainfall[i])     # column 2: exogenous
    return out

# Z-score: standard deviations away from the mean (used for anomalies)

# Full Mojo pipeline: load and split data natively, fit Holt-Winters via
# Python interop (pandas + statsmodels), then evaluate MAE in Mojo.
from std.python import Python

# Mojo has no std.python.numpy: hand the split over as a real Python list.
def to_python_list(data: List[Float64]) raises:
    var out = Python.list()
    for v in data:
        out.append(v)
    return out

def main() raises:
    # 1. Load data as a typed Mojo List
    var data: List[Float64] = [
        120.0, 132.0, 145.0, 138.0, 150.0, 165.0, 170.0,
        158.0, 175.0, 190.0, 185.0, 200.0, 210.0, 205.0,
        220.0, 215.0, 230.0, 240.0, 235.0, 250.0, 260.0,
        255.0, 270.0, 280.0,
    ]
    # 2. Chronological split (train: first 18, test: last 6)
    var train = List[Float64]()
    var test = List[Float64]()
    for i in range(18):
        train.append(data[i])
    for i in range(18, 24):
        test.append(data[i])
    # 3. Fit via Python interop: Mojo List -> Python list -> pandas Series
    var pd_module = Python.import_module("pandas")
    var statsmodels = Python.import_module("statsmodels.tsa.holtwinters")
    var train_series = pd_module.Series(to_python_list(train))
    var hw = statsmodels.ExponentialSmoothing(
        train_series, trend="add", seasonal="add", seasonal_periods=12,
    )
    var model = hw.fit()
    # 4. Forecast the next 6 months
    var forecast = model.forecast(6)
    # 5. Evaluate: mean absolute error against the held-out test set
    var mae: Float64 = 0.0
    for i in range(6):
        var diff = test[i] - Float64(forecast.values[i])
        if diff < 0.0:              # absolute value (sign check)
            diff = -diff
        mae += diff
    mae /= 6.0
    print("Forecast:", forecast.values)
    print("Test MAE:", mae)
