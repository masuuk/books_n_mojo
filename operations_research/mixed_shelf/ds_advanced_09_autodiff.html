📉 Autodiff & Optimization

Reverse-mode automatic differentiation, SGD/Adam optimizers, gradient descent loops, and loss functions — the building blocks of machine learning.

Reverse-Mode Automatic Differentiation

Automatic differentiation (AD) computes exact derivatives of programs defined by compositions of elementary operations. Unlike numerical differentiation (finite differences), AD is exact to machine precision and runs in time proportional to evaluating the function itself.

How Reverse-Mode AD Works

Reverse-mode AD (backpropagation) first runs a forward pass to compute the function value and record a tape of operations. Then it runs a backward pass that propagates derivatives from the output back to the inputs. This is efficient when there are many inputs and one output — exactly the case in loss function evaluation.

Mojo 1.x
// Mojo's autodiff uses the ADT (Automatic Differentiation Type) system
from autodiff import gradient, Value

def quadratic(x: Value) -> Value:
    // f(x) = 3x² + 2x + 1
    return 3.0 * x * x + 2.0 * x + 1.0

def rosenbrock(x: Value, y: Value) -> Value:
    // f(x,y) = (1-x)² + 100(y-x²)²
    var a = 1.0 - x
    var b = y - x * x
    return a * a + 100.0 * b * b


// Compute gradients
var df_dx = gradient(quadratic)
print(df_dx(2.0))  // f'(2) = 12 + 2 = 14.0

// Multi-variable gradient
var grad = gradient(rosenbrock)
var (dx, dy) = grad(1.0, 1.0)
print(dx, dy)  // (0.0, 0.0) — minimum at (1,1)
Mojo's AD advantage:

Python autograd frameworks (PyTorch, JAX) build a dynamic computation graph at runtime. Mojo's AD operates at compile time — the graph is known statically, so the backward pass can be fully fused and vectorized. This eliminates graph construction overhead and enables operator fusion.

SGD and Adam Optimizers

Stochastic Gradient Descent (SGD) is the foundation of neural network training. Adam combines momentum with adaptive learning rates, converging faster on most problems.

Mojo 1.x
struct Adam:
    var lr: Float64
    var beta1: Float64
    var beta2: Float64
    var eps: Float64
    var t: Int
    var m: Dict[String, Float64]
    var v: Dict[String, Float64]

    def __init__(
        mut self,
        lr: Float64 = 0.001,
        beta1: Float64 = 0.9,
        beta2: Float64 = 0.999,
        eps: Float64 = 1e-8
    ):
        self.lr = lr
        self.beta1 = beta1
        self.beta2 = beta2
        self.eps = eps
        self.t = 0
        self.m = Dict[String, Float64]()
        self.v = Dict[String, Float64]()

    def step(mut self, params: Dict[String, Float64], grads: Dict[String, Float64]):
        self.t += 1
        for key in grads:
            var g = grads[key]

            // Update biased moments
            self.m[key] = self.beta1 * self.m.get(key, 0.0) + (1.0 - self.beta1) * g
            self.v[key] = self.beta2 * self.v.get(key, 0.0) + (1.0 - self.beta2) * g * g

            // Bias correction
            var m_hat = self.m[key] / (1.0 - self.beta1 ** Float64(self.t))
            var v_hat = self.v[key] / (1.0 - self.beta2 ** Float64(self.t))

            // Update parameters
            params[key] -= self.lr * m_hat / (sqrt(v_hat) + self.eps)


def sgd_step(
    mut params: List[Float64],
    grads: List[Float64],
    lr: Float64
):
    for i in range(len(params)):
        params[i] -= lr * grads[i]

Gradient Descent Loop

The training loop is the heart of optimization: compute loss, backpropagate gradients, update parameters, repeat. Mojo's zero-cost abstractions make this loop as fast as hand-written C.

Mojo 1.x
from autodiff import gradient, Value
from math import sqrt, exp

def linear_regression(
    x_data: List[Float64],
    y_data: List[Float64],
    lr: Float64 = 0.01,
    epochs: Int = 1000
) -> (Float64, Float64):
    // Learn y = w*x + b
    var w = 0.0
    var b = 0.0
    var n = Float64(len(x_data))

    for epoch in range(epochs):
        // Forward pass: compute MSE loss
        var loss = 0.0
        var dw = 0.0
        var db = 0.0

        for i in range(len(x_data)):
            var pred = w * x_data[i] + b
            var err = pred - y_data[i]
            loss += err * err
            dw += 2.0 * err * x_data[i] / n
            db += 2.0 * err / n

        loss /= n

        // Update parameters
        w -= lr * dw
        b -= lr * db

        if epoch % 200 == 0:
            print("Epoch", epoch, "loss =", loss)

    return (w, b)


// Generate synthetic data: y = 3x + 1 + noise
var x_data = List[Float64]()
var y_data = List[Float64]()
for i in range(100):
    var x = Float64(i) / 10.0
    x_data.append(x)
    y_data.append(3.0 * x + 1.0 + Normal(0.0, 0.5).sample())

var (w, b) = linear_regression(x_data, y_data)
print("Learned: y =", w, "* x +", b)

Loss Functions

Loss functions quantify how wrong your model's predictions are. Different tasks require different losses, and understanding their gradients is crucial for stable training.

Common Loss Functions

  • MSE (Mean Squared Error): For regression — penalizes large errors quadratically.
  • MAE (Mean Absolute Error): For robust regression — less sensitive to outliers.
  • Cross-Entropy: For classification — measures divergence between predicted and true distributions.
  • Huber Loss: Combines MSE and MAE — quadratic near zero, linear for large errors.
Mojo 1.x
from std.math import log, exp, abs

def mse_loss(pred: List[Float64], target: List[Float64]) -> Float64:
    var total = 0.0
    for i in range(len(pred)):
        var diff = pred[i] - target[i]
        total += diff * diff
    return total / Float64(len(pred))


def binary_cross_entropy(pred: List[Float64], target: List[Float64]) -> Float64:
    var total = 0.0
    var eps = 1e-7
    for i in range(len(pred)):
        var p = max(eps, min(1.0 - eps, pred[i]))
        total -= target[i] * log(p) + (1.0 - target[i]) * log(1.0 - p)
    return total / Float64(len(pred))


def huber_loss(pred: List[Float64], target: List[Float64], delta: Float64 = 1.0) -> Float64:
    var total = 0.0
    for i in range(len(pred)):
        var a = abs(pred[i] - target[i])
        if a <= delta:
            total += 0.5 * a * a
        else:
            total += delta * (a - 0.5 * delta)
    return total / Float64(len(pred))
💡 Tip:

In Mojo, loss functions can be written as generic structs that work with any numeric type. The compiler generates specialized code for Float32 and Float64, avoiding dynamic dispatch overhead.
