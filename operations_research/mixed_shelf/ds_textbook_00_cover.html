01 — Orientation

🔥 Why put Mojo next to Python?

Because most data scientists already live in exactly this pair, whether they've named it or not.

Python

Where the ideas live

NumPy, pandas, PyTorch, scikit-learn — the entire research ecosystem. Fast to write, slow to run, and the boundary where prototypes quietly become production liabilities.

Mojo

Where the guarantees live

Compile-time checks that catch type and memory errors before anything runs — the safety you'd normally have to leave Python for, without leaving Python's way of writing code behind.

Mojo

Where they meet

Python-family syntax with a compiler built on MLIR, so the same code can target CPUs, GPUs, and accelerators without rewrites.

02 — A Taste

⚡ The same idea, in one language

A small numerical kernel — computing the mean of a vector — written in Mojo. Notice how Mojo keeps Python's reading experience while gaining the speed of a compiled language.

def mean(values: List[Float64]) -> Float64:
    var total: Float64 = 0.0
    for v in values:
        total += v
    return total / Float64(len(values))

def main():
    var data = List[Float64](2.0, 4.0, 6.0, 8.0)
    print("mean =", mean(data))  # mean = 5.0

Same shape as Python, a fully-annotated def gives you a strictly-typed, checked function, and var is required for mutable locals. Chapter 1 unpacks this line by line.
